To-Do List 📝

A responsive and interactive To-Do List web app built with HTML, CSS, and JavaScript for creating, managing, and completing daily tasks.

✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Interactive and responsive UI
- Clean and simple design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
